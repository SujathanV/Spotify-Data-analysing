
# Spotify Data Analysis Project

## Project Overview

This project focuses on analyzing Spotify music data to discover meaningful insights about tracks, genres, popularity, and audio features.

The project processes 114,000+ Spotify tracks using Python and Pandas, stores the cleaned data in SQLite3, and presents key insights through an interactive Power BI dashboard.

## Project Objectives

- Analyze 114K+ Spotify tracks.
- Clean and transform raw music data.
- Explore track popularity and music genres.
- Analyze audio features such as danceability.
- Build an interactive Power BI dashboard.
- Identify meaningful trends and patterns in Spotify music data.

## Technologies Used

- Python
- Pandas
- NumPy
- SQLite3
- Power BI
- Jupyter Notebook

## ETL Workflow

### 1. Extract
- Imported Spotify dataset into Python.
- Loaded raw data using Pandas.

### 2. Transform
- Checked missing values and duplicates.
- Cleaned and processed the dataset.
- Prepared data for analysis.

### 3. Load
- Stored the processed dataset in SQLite3.
- Used the cleaned data for further analysis and visualization.

## Power BI Dashboard

The Power BI dashboard provides insights into:

- Total number of tracks.
- Average track popularity.
- Average danceability.
- Genre-wise music distribution.
- Interactive charts and slicers for exploration.

## Key Findings

- Analyzed more than 114,000 Spotify tracks.
- Explored 114 music genres.
- Examined track popularity across the dataset.
- Studied danceability and other audio characteristics.
- Used visualizations to understand music trends.
